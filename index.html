MSc research · University of Exeter · 2026

MACS: a multi-agent coding studio with trace-based measurement

Does a team of AI agents produce more varied and original correct code than a single AI assistant? I built the system, the measuring instrument and the experiment to find out. Supervised by Prof. Solomon S. Oyelere.

  • SystemA Python package of about 45 modules. Four role agents work on a programming task, and a Facilitator uses code embeddings to detect when their ideas converge.
  • MeasurementEvery solution is scored from the session trace: correctness on held-out tests, novelty against 100 reference solutions, and diversity by clustering solutions into families by code structure.
  • ExperimentA pre-registered study: 11 conditions, 27 tasks and 6 seeds across 8 models, run as self-resubmitting Slurm jobs on A100 GPUs.
  • StatisticsMixed models with planned contrasts and Holm correction, plus a random-effects meta-analysis across all 8 models.
  • ReliabilitySchema-validated JSONL traces, a hash-keyed cache so any run can be replayed exactly, a sandbox for generated code, and a Streamlit dashboard.
